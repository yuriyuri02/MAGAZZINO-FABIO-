# Magazzino

Gestionale di magazzino con categorie, quantità, codice e descrizione.
Funziona offline e salva i dati nel browser del dispositivo.

## Pubblicare su GitHub Pages

1. Crea un repository su GitHub (es. `magazzino`).
2. Carica tutti i file di questa cartella nella radice del repository.
3. Vai in Settings > Pages, scegli "Deploy from a branch", branch `main`, cartella `/ (root)`, poi Save.
4. Dopo un minuto circa l'app è su `https://TUO-UTENTE.github.io/magazzino/`.

## Usarla come app sul telefono

Apri il link in Safari (iPhone) o Chrome (Android), poi "Aggiungi a schermata Home".
Dopo la prima apertura funziona anche senza connessione.

## Dati

I dati sono salvati nel browser di ogni dispositivo, non sono condivisi tra persone.
Usa "Salva backup" ogni tanto: se cancelli i dati del browser, l'elenco si perde.
